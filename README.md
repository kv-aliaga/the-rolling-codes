# The Rolling Codes

[Acesse nosso site!](https://kv-aliaga.github.io/the-rolling-codes/)

Nós somos os Rolling Codes, grupo do trabalho de DEVOPS do 2º Ano Tech do Instituto J&F.

Nos foi requisitado um trabalho para treinar os conceitos de **pull request**, **code review** e **git/github**.

Para isso um tema: *"Um lugar que gostariamos de conhecer"*.

## Sobre o site:
É importante esclarecer algumas coisa antes:
  1. O site foi feito com o intuito de falar sobre um lugar que gostariamos de conhecer com base em outra coisa que gostamos;
  2. O CSS de cada página assim como o de outros grupos do 2º ano E, é individual por página, e cada membro foi responsável pelo seu.

## Tecnologias Usadas

  - CSS3
  - Git
